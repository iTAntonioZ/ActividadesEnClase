# ADA4 - Métodos de búsqueda
Tres ejercicios independientes integrados en un menú. Requiere Python 3; no necesita librerías externas.

## Ejecutar
```bash
python main.py
python -m unittest -v
```
También se puede ejecutar cada método por separado con `python secuencial.py`, `python binaria.py` o `python hash_busqueda.py`.

- Secuencial: buscar un producto en una lista sin ordenar.
- Binaria: buscar una matrícula en una lista ordenada.
- Hash: consultar un teléfono mediante un diccionario.

Los datos son ejemplos ficticios. La búsqueda binaria requiere datos ordenados. Los nombres se consultan tal como aparecen en pantalla, sin distinguir mayúsculas.
